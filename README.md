# Noush Zia — Personal Portfolio

A bilingual personal portfolio showcasing my background in Industrial Design, Content Strategy, and my journey toward Product Management.

The website brings together my professional experience, selected projects, and product-related skills in a responsive, editorial-style interface.

## About the Project

This portfolio was created to present my professional journey, highlight selected work, and communicate my transition toward Product Management.

It includes:
- A bilingual interface (Persian and English)
- Responsive layouts for desktop and mobile
- Light and dark theme options
- Interactive career timeline
- Selected projects and case studies
- Downloadable Persian and English resumes

## AI-Assisted Design & Development

This project was developed through an AI-assisted workflow.

I used AI tools to support code generation, implementation, debugging, and refinement. My contribution included:

- Defining the project requirements and overall direction
- Making visual and UX decisions
- Structuring the content and user journey
- Guiding AI-assisted implementation
- Reviewing generated code and testing the interface
- Iterating on the design and resolving implementation issues

The project reflects my interest in applying AI tools to practical product and design workflows.
